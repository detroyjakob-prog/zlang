Why Z

A language that says what it means.

Z trades cryptic punctuation for plain keywords. The result reads almost like prose — and never surprises you with hidden behavior.

{ }

Keyword-driven by design

Every action starts with a keyword: call, callclass, abl, callerror. If you can read it, you understand it.

: T

Types, optional

Write abl int y = 2 or just abl y = 2. Types are a tool, never a tax — annotate when it helps.

;

No semicolons

Newlines end statements. Braces { } delimit blocks. Clean, consistent, and free of line-end noise.

fn

First-class functions

Lambdas, closures, and generators are built in. fn(x) => x + 1 is a value you can pass around.

⬡

Classes & objects

Inheritance with super, dunder-style methods, enums, and privacy by convention with a leading _.

↻

Async & concurrency

Mark a function async fn, await calls, and fan out work with gather. Non-blocking by default.

⌸

Batteries included

Standard libraries for math, random, time, files, json, os and strings.

✓

Garbage collected

Memory is managed automatically. Reference types share references; scalars stay immutable and safe.

⧉

Standalone builds

z build file.z emits a single self-contained executable with your program appended to it.

Readable by default

Syntax you can read out loud.

Compare a familiar snippet with Z's spelling. Same logic — but every step announces itself.

  • ✓Declare a variable with abl — one keyword, no ceremony.
  • ✓Call a function with call, a method with callclass.
  • ✓Raise errors with callerror — explicit and greppable.
  • ✓Blocks use { }, conditions wrap in optional parens.
●greet.z
// every action is a keyword
fn Greet(name) {
    abl greeting = f"Hello {name}!"
    call printer(greeting)
}

fn Main() {
    abl names = ["Ada", "Zed"]
    for n in names {
        call Greet(n)
    }
    try {
        abl x = call int("oops")
    } except ValueError as e {
        call printer(f"Caught: {e}")
    }
}
The tour

Familiar power, spelled out.

From control flow to classes and async — here's how everyday patterns look in Z. Click through the tabs.

●control.z
abl score = 92

if score >= 90 {
    call printer("A")
} elif score >= 80 {
    call printer("B")
} else {
    call printer("C")
}

match "stop" {
    case "start" { call printer("go") }
    case "stop", "quit" { call printer("halt") }
    case _ { call printer("?") }
}

// comprehensions & closures
abl squares = [x * x for x in call range(6)]
abl double = fn(x) => x * 2
●shapes.z
Shape {
    fn init(self, name) { self.name = name }

    fn Area(self) {
        return 0
    }
}

Circle(Shape) {
    fn init(self, r) {
        callclass super.init("circle")
        self.r = r
    }

    fn Area(self) {
        return 3.14159 * self.r ** 2
    }
}

abl c = callclass Circle(2)
call printer(c)
●funcs.z
// closures capture their environment
fn MakeCounter(start) {
    abl count = start
    fn Step() {
        outer count
        count += 1
        return count
    }
    return Step
}

// generators with yield
fn Countdown(n) {
    while n > 0 {
        yield n
        n -= 1
    }
}

abl next = call MakeCounter(10)
for v in call Countdown(3) {
    call printer(v)
}
●async.z
async fn Fetch(url) {
    abl data = await call http.get(url)
    return data
}

async fn Main() {
    abl one = await call Fetch("one")

    // run several calls together
    abl results = await call gather(
        call Fetch("one"),
        call Fetch("two")
    )
}

// await is only valid inside async fn
The toolchain

One command, z.

A single, dependency-free binary compiles and runs your programs. Everything is a subcommand.

z run file.zRun a program
z check file.zCheck syntax without running
z build file.zBuild a standalone executable
z replStart the interactive prompt
z --versionPrint the version
z helpShow usage and all commands
Get started

From zero to Hello, Z! in three steps.

Install Rust, build the toolchain, and run your first program.

1

Install Rust

Z is built with a nightly toolchain via rustup. Grab it and set the default:

$ rustup toolchain install nightly
$ rustup default nightly
2

Build Z

Clone the repository and compile the release binary:

$ git clone …/zlang.git
$ cd zlang && cargo build --release
3

Run it

Write a program and run it with the z binary:

$ z run hello.z
Hello, Z!
